# Functional and diet association analyses

This directory contains the protein-modelling workflow and the population-level analysis of the association between *PGA* copy number and dietary protein composition.

## Requirements

For protein structure and molecular modelling:

- AlphaFold 3
- PyRosetta
- CHARMM-GUI
- GROMACS
- MDAnalysis

For the diet-association analysis:

- Python 3
- pandas
- NumPy
- SciPy
- Matplotlib

## Protein structure and molecular modelling

The structural analysis uses AlphaFold 3 to model the mature PGA34A enzyme in complex with the octapeptide substrate LSFMAIPP. PGA34B and PGA5 structures are generated by introducing isoform-specific substitutions with PyRosetta, and the final complexes are locally repacked using the protocol described in the manuscript. Molecular-dynamics systems are prepared with CHARMM-GUI under acidic conditions and simulated with GROMACS. MDAnalysis is used to quantify catalysis-ready water conformations relative to the D32/D215 catalytic dyad and the scissile peptide carbonyl.

The publication-ready modelling, MD, and frame-selection workflow is provided in [`protein_structure_md`](protein_structure_md/). Its main entry points are:

```bash
python protein_structure_md/build_isoform_models.py \
    --input <PGA34A_LSFMAIPP.pdb> \
    --output-dir models

bash protein_structure_md/md_example/run_md_replicates.sh \
    <system_directory>

python protein_structure_md/analysis/select_catalysis_ready_frames.py \
    --manifest <manifest.tsv> \
    --output-dir analysis_results
```

## Association between *PGA* CN and plant-derived protein fraction

Dietary protein composition was obtained from [FAOSTAT Food Balances](https://www.fao.org/faostat/en/#data/FBSH). We used the old-methodology Food Balances records from 1961–1980.

First, prepare the country-level plant-derived protein fraction table from the downloaded FAOSTAT CSV:

```bash
python prepare_faostat.py \
    --input <FAOSTAT_Food_Balances.csv> \
    --output fao_baseline_1961_1980.csv
```

The script calculates the fraction of total protein supply contributed by plant-derived products and averages it across 1961–1980.

The *PGA* CN–diet association uses the 1KGP cohort. Prepare the inferred diploid *PGA* CN table, 1KGP population metadata, the diploid PCA table from [`population_structure`](../population_structure/), and the FAOSTAT table generated above. Run:

```bash
python pga_diet_association.py \
    --cnv <1KGP_PGA_CN.tsv> \
    --metadata <1KGP_metadata.tsv> \
    --pca <joint_diploid_PCA.tsv> \
    --fao fao_baseline_1961_1980.csv \
    --out-prefix pga_diet
```

The script retains 1KGP samples with defined study superpopulation labels, maps populations to interpretable FAOSTAT regions, and calculates regional mean diploid *PGA* CN and regional mean PC1–PC3. It reports the unadjusted Spearman correlation with a two-sided permutation P value and the PC1–PC3-adjusted partial Spearman correlation with a two-sided Freedman–Lane permutation P value. Both tests use 100,000 permutations by default.

Main outputs:

```text
pga_diet.sample_match.tsv
pga_diet.region_data.tsv
pga_diet.statistics.tsv
pga_diet.raw.pdf
pga_diet.pc_adjusted.pdf
```
