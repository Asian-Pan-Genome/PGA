# PGA protein structure and molecular dynamics

Construction of PGA34A, PGA34B, and PGA5 protein–LSFMAIPP complexes, five independent 100-ns molecular-dynamics replicates per isoform, and analysis of catalysis-ready water geometries.

Residue numbers below refer to the mature enzyme.

## Isoform models

Starting from the AlphaFold 3 PGA34A–LSFMAIPP complex after removal of the 62-residue signal peptide and activation propeptide:

```bash
python build_isoform_models.py \
    --input PGA34A_LSFMAIPP.pdb \
    --output-dir models
```

PGA34B is generated by V30L substitution; PGA5 by Q160K, A203T, and L291V substitutions. PyRosetta locally repacks side chains within 6 Å of the altered residues; the PGA34A model is locally repacked without sequence change.

## Molecular dynamics

Systems are prepared with CHARMM-GUI using CHARMM36m/TIP3P under acidic conditions, with D32 deprotonated and D215 protonated. Each isoform is simulated in five independent 100-ns GROMACS replicates at 310 K and 1 bar. Frames from 20–100 ns are retained at 0.5-ns intervals.

The deposited `mdp/` files contain the minimization, equilibration, and production settings. Run replicates with:

```bash
bash run_md_replicates.sh /path/to/SYSTEM 1 2 3 4 5
```

## Catalysis-ready water geometry

```bash
python select_catalysis_ready_frames.py \
    --data-dir /path/to/MD_DATA \
    --output-dir analysis_results
```

`Csc` and `Osc` denote the carbonyl carbon and oxygen of Phe at the Phe–Met scissile bond. A frame is counted once when at least one water molecule satisfies all criteria at a given threshold.

| Level | Asp–Ow criterion | Ow–Csc | Ow–Csc–Osc angle |
| --- | --- | ---: | ---: |
| L1 | both ≤ 3.5 Å | ≤ 3.2 Å | 100–110° |
| L2 | both ≤ 3.5 Å | ≤ 3.5 Å | 95–115° |
| L3 (primary) | both ≤ 4.0 Å | ≤ 3.5 Å | 95–120° |
| L4 | both ≤ 4.0 Å | ≤ 4.0 Å | 90–125° |
| L5 | one ≤ 4.0 Å and both ≤ 5.0 Å | ≤ 4.5 Å | 90–130° |

The water-geometry analysis provides structural support for isoform-specific active-site conformations; it is not a direct estimate of catalytic rate.
