# PGA protein-structure and MD workflow

Code for model construction, five independent 100 ns MD replicates, and
catalysis-ready water analysis of PGA–LSFMAIPP complexes.

## Requirements

- PyRosetta 2026.3
- CHARMM-GUI
- GROMACS 2024
- Python 3 with MDAnalysis, NumPy, and pandas

Residue numbers refer to the mature enzyme.

## 1. Model construction

Use the AlphaFold 3 PGA34A–LSFMAIPP complex after removal of the N-terminal
62-residue signal peptide and activation propeptide:

```bash
python build_isoform_models.py \
  --input PGA34A_LSFMAIPP.pdb \
  --output-dir models
```

- PGA34A: repack residues within 6 Å of positions 160 and 203, without mutation.
- PGA34B: V30L, then repack within 6 Å of position 30.
- PGA5: Q160K, A203T, and L291V, then repack within 6 Å of these positions.

Repacking uses `PackRotamersMover`, `get_fa_scorefxn()`,
`restrict_to_repacking()`, and `or_include_current(True)`. The script validates
the VQAL, LQAL, and VKTV marker sequences and the LSFMAIPP peptide.

## 2. CHARMM-GUI preparation

- pH 1.5 protonation assignment
- deprotonated D32 and protonated D215
- CHARMM36m and TIP3P
- approximately 8.40 × 8.40 × 8.40 nm³ periodic box
- neutralization and approximately 0.13 M NaCl

Use the topology, coordinates, index, and `toppar/` directory generated by
CHARMM-GUI. Copy the three files in `mdp/` into each system's `input/`
directory:

```text
SYSTEM/
└── input/
    ├── step3_input.gro
    ├── topol.top
    ├── index.ndx
    ├── toppar/
    ├── step4.0_minimization.mdp
    ├── step4.1_equilibration.mdp
    └── step5_production.mdp
```

The supplied files preserve the CHARMM-GUI minimization and 125 ps
equilibration settings. Production was extended to 100 ns with `dt = 0.002`,
`nsteps = 50000000`, and `nstxout-compressed = 250000`. The same files were
used for every system and replicate. They use velocity-rescaling at 310 K,
isotropic C-rescale pressure coupling at 1 bar, PME electrostatics with a
1.2 nm cutoff, van der Waals force switching from 1.0 to 1.2 nm, and LINCS
constraints on bonds involving hydrogen atoms.

## 3. MD simulation

```bash
bash run_md_replicates.sh /path/to/SYSTEM 1 2 3 4 5
```

Each replicate includes restrained minimization, 125 ps restrained
equilibration at 310 K, and 100 ns production at 310 K and 1 bar. Initial
velocities are generated independently with `gen-seed = -1`. Production uses a
2 fs step and saves coordinates every 0.5 ns.

The script applies `-pbc mol -center`, backbone `-fit rot+trans`, and retains
20–100 ns (161 frames). Default index groups are Protein=1, Backbone=4, and
System=0; they can be overridden with `CENTER_GROUP`, `FIT_GROUP`, and
`OUTPUT_GROUP`.

Optional hardware arguments can be supplied through `GMX_MDRUN_ARGS`:

```bash
GMX_MDRUN_ARGS="-nb gpu -bonded gpu -pme gpu" \
  bash run_md_replicates.sh /path/to/SYSTEM
```

## 4. Catalysis-ready frame analysis

Arrange the processed trajectories as follows:

```text
MD_DATA/
├── PGA34A/rep1 ... rep5/
├── PGA34B/rep1 ... rep5/
└── PGA5/rep1 ... rep5/
```

Each replicate directory must contain `step5_ref.tpr` and
`md_fit_20_100ns.xtc`. Run:

```bash
python select_catalysis_ready_frames.py \
  --data-dir /path/to/MD_DATA \
  --output-dir analysis_results
```

`Csc` and `Osc` are the carbonyl carbon and oxygen of Phe in the Phe–Met
scissile bond. Each Asp–Ow distance is measured to the nearer carboxyl oxygen
of D32 or D215. A frame is a hit when at least one water satisfies all criteria
at a given level.

| Level | Asp–Ow criterion | Ow–Csc | Ow–Csc–Osc angle |
|---|---|---:|---:|
| L1 | both ≤ 3.5 Å | ≤ 3.2 Å | 100–110° |
| L2 | both ≤ 3.5 Å | ≤ 3.5 Å | 95–115° |
| L3 (primary) | both ≤ 4.0 Å | ≤ 3.5 Å | 95–120° |
| L4 | both ≤ 4.0 Å | ≤ 4.0 Å | 90–125° |
| L5 | one ≤ 4.0 Å and both ≤ 5.0 Å | ≤ 4.5 Å | 90–130° |

The main analysis uses L3. Output includes selected L3 frames and waters,
counts by replicate and system, and L1–L5 sensitivity results.
