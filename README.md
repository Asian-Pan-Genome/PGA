# *PGA*

Code supporting analyses of pepsinogen A (*PGA*) copy-number and structural variation in humans and mammals.

## Analyses

| Directory | Scope |
| --- | --- |
| [`pga_annotation/`](pga_annotation/) | Human and ape *PGA* annotation. |
| [`population_structure/`](population_structure/) | Joint assembly–1KGP PCA of broad genetic structure. |
| [`cn_genotyping/`](cn_genotyping/) | Short-read inference of total and paralog-specific *PGA* copy number. |
| [`genomewide_cnv/`](genomewide_cnv/) | Genome-wide gene-family copy-number differentiation. |
| [`paralog_evolution/`](paralog_evolution/) | *PGA* paralog phylogeny, divergent sites, and predicted high-impact variants. |
| [`structural_haplotypes/`](structural_haplotypes/) | Structural haplotypes, duplicons, and NAHR analyses at the human *PGA* locus. |
| [`population_genetics/`](population_genetics/) | Local pangenome variation, population-genetic statistics, neutral simulations, and genealogies. |
| [`ancient_dna/`](ancient_dna/) | Temporal analyses of *PGA* copy number and local diversity in ancient Eurasian genomes. |
| [`functional_diet_association/`](functional_diet_association/) | Protein modelling, molecular dynamics, and population-level *PGA* CN–diet association analyses. |
| [`cn_snp_linkage/`](cn_snp_linkage/) | SNP associations with *PGA34A* copy number in 1KGP populations. |
| [`ukb_association/`](ukb_association/) | UK Biobank molecular-trait association and PheWAS analyses. |
| [`mammalian_evolution/`](mammalian_evolution/) | Mammalian *PGA* annotation, comparative analyses, copy-number dynamics, and repeat context. |
