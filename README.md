# *PGA*

Code associated with analyses of copy-number and structural variation at the human pepsinogen A (*PGA*) locus, population differentiation, functional and dietary associations, and comparative evolution across mammals.

This repository is organized by major analysis blocks rather than by figure. It is intended as a publication code archive rather than a single end-to-end workflow. Custom scripts are included where they were used in the study; dataset curation, manual inspection, or analyses performed directly with standard software may instead be described in the corresponding module README.

## Repository structure

| Directory | Overview |
| --- | --- |
| [`pga_annotation/`](pga_annotation/) | Annotation and characterization of *PGA* genes in human and ape genome assemblies. |
| [`population_structure/`](population_structure/) | Principal-component analysis of the human assembly cohort for assessment of genetic ancestry and population structure. |
| [`cn_genotyping/`](cn_genotyping/) | Short-read copy-number genotyping of the *PGA* locus and paralog-specific copy-number estimation. |
| [`genomewide_cnv/`](genomewide_cnv/) | Genome-wide contextualization of population differentiation in gene copy number. |
| [`paralog_evolution/`](paralog_evolution/) | Phylogenetic and sequence analyses of human *PGA* paralogs and their evolutionary divergence. |
| [`structural_haplotypes/`](structural_haplotypes/) | Pangenome-based structural decomposition, structural-haplotype classification, and recombination analyses of the human *PGA* locus. |
| [`population_genetics/`](population_genetics/) | Population-genetic analyses of the *PGA* locus in modern human populations. |
| [`ancient_dna/`](ancient_dna/) | Temporal analyses of *PGA* copy number and local genetic variation using ancient genomes. |
| [`functional_diet_association/`](functional_diet_association/) | Functional analyses of PGA protein isoforms and population-level associations between *PGA* copy number and dietary composition. |
| [`cn_snp_linkage/`](cn_snp_linkage/) | Analyses of sequence variants and haplotypes associated with *PGA* copy number. |
| [`ukb_association/`](ukb_association/) | Molecular-trait and phenotype association analyses of *PGA* copy number in UK Biobank. |
| [`mammalian_evolution/`](mammalian_evolution/) | Comparative analyses of *PGA* copy-number and structural evolution across mammals. |
